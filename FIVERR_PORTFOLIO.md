# Fiverr Portfolio Package — VELORA

## Recommended project title
**Premium Full-Stack MERN Fashion E-Commerce Website**

## Short description
VELORA is a premium responsive fashion e-commerce experience built with React, Vite, Node.js, Express and MongoDB-ready APIs. The project includes a multi-image product gallery, advanced filtering, wishlist, persistent cart, JWT authentication, customer accounts, checkout, order history, admin product CRUD, order management, customer records, contact messages and optional Stripe test checkout.

## Technologies
React 19 · Vite · React Router · JavaScript ES6+ · Node.js · Express.js · MongoDB/Mongoose · JWT · bcrypt · REST API · Stripe test-mode scaffold · Responsive CSS

## Key portfolio features
- 35+ public/account/admin routes
- 18 seeded fashion products
- 4 distinct gallery images per product
- Product image thumbnails + click zoom
- Sizes, colour variants and stock status
- Related products and reviews
- Product search, sort, type, stock and price filters
- Wishlist and persistent shopping bag
- Full-stack register/login with bcrypt + JWT
- Protected account, checkout and admin routes
- 3-step checkout
- Orders stored through the API
- Order tracking/status display
- MongoDB Atlas support with in-memory fallback for local demo
- Admin dashboard with revenue/orders/customers/inventory
- Add/edit/delete products
- Update order status
- Customer directory and contact-message inbox
- Contact and newsletter APIs
- Responsive desktop/tablet/mobile layout
- Vercel + Render deployment configuration
